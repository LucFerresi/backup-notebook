Política de Privacidade — backup-notebook

Vigente desde 16 de outubro de 2026.

1. O que é

O backup-notebook é um cliente OAuth de uso exclusivo do seu titular, que o usa para gravar cópias de segurança do próprio computador no próprio Google Drive, por meio das ferramentas rclone e restic.

2. Dados acessados

O aplicativo pede somente a permissão drive.file: ele acessa apenas os arquivos e pastas que ele mesmo criou no Drive. Não lê nenhum outro arquivo, e-mail, contato ou dado da conta Google.

3. Como os dados são tratados

As cópias são cifradas no próprio computador (restic, AES-256) antes do envio. Nem o Google nem terceiros recebem o conteúdo legível. Nenhum dado é coletado, vendido, compartilhado ou enviado a servidor do desenvolvedor: o aplicativo não tem servidor.

4. Armazenamento e exclusão

Os dados ficam apenas na conta Google do próprio titular, que pode apagá-los a qualquer momento. O acesso pode ser revogado em myaccount.google.com/permissions.

5. Uso dos dados do Google

O uso das informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.
